## Notes recorded while reading

- **The 64×64 listing icon is the one asset the requirements ask for that the build does not make.** AMO asks
  for 32×32 and 64×64 for the listing; the manifest's `icons` are a separate thing. 10.3 covers it.
- **CWS name and short description come from the manifest**, not from a dashboard field, so they are already in
  `public/_locales/{es,en}/messages.json` — one string, two places that must agree (C1, C2).
- **AMO asks for a privacy policy only when data is transmitted.** NacioCheck transmits nothing, so the field is
  optional; the site's policy (Phase 9) will still be offered, and the `none` declaration is the machine-readable
  answer (A5).
- **`strict_min_version: 128.0` with `data_collection_permissions`.** Old Firefox ignores the key; because the
  answer is `none`, there is no data collection to disclose on 128–139 either, which is exactly why the policy
  only demands a custom consent experience from add-ons that collect something (A5).
- **AMO reviews by rebuilding.** The source package must contain everything `npm ci && npm run build:firefox`
  needs and nothing that only exists locally (A2).

## Notes recorded while reading

- **The 64×64 listing icon was the one asset the requirements asked for that the build does not make.** AMO asks
  for 32×32 and 64×64 for the listing; the manifest's `icons` are a separate thing. `npm run store:images` now
  renders both from `brand/icon.svg`.
- **CWS name and short description come from the manifest**, not from a dashboard field, so they are already in
  `public/_locales/{es,en}/messages.json` — one string, two places that must agree (C1, C2).
- **AMO asks for a privacy policy only when data is transmitted.** NacioCheck itself transmits nothing, so the
  field is optional; the site's policy in `site/privacy/` will still be offered, and the `none` declaration is the
  machine-readable answer (A5).
- **`strict_min_version: 128.0` with `data_collection_permissions`.** Old Firefox ignores the key; because the
  answer is `none`, there is no data collection to disclose on 128–139 either, which is exactly why the policy
  only demands a custom consent experience from add-ons that collect something (A5).
- **`gecko_android` is intentionally empty.** It inherits the desktop minimum instead of excluding older Android
  versions; the linter warning is accepted until the target is device-verified (A6).
- **AMO reviews by rebuilding.** The source package must contain everything `npm ci && npm run build:firefox`
  needs and nothing that only exists locally (A2).
- **Browser packages carry the licence and third-party notices.** The build copies the canonical root `LICENSE`
  and `THIRD-PARTY-NOTICES.txt` into both the Chrome and Firefox packages; the source archive contains the same
  files. `npm run check:privacy` asserts both in each build. The notice covers the WXT 0.21.5 and
  `@wxt-dev/browser` 0.3.7 runtime code compiled into the bundles (MIT, Copyright (c) 2023 Aaron).
- **Android is verified on a device.** Viewport metadata alone was not enough; the owner's device run on
  2026-11-24 passed, so the listing may claim Android support (A6).
- **Re-read on 2026-11-25 (1.0.0): no limit changed.** Chrome name 75 and description 132 characters; store icon
  128×128; screenshots 1 to 5 at 1280×800 or 640×400; promo tiles 440×280 and 1400×560, not localized; the
  keyword rule is still "more than 5 times"; AMO package 200 MB, source package 200 MB, summary 250 characters,
  up to 2 categories per platform, listing icons 32×32 and 64×64, screenshots 1280×800 recommended; data
  consent required since 2025-11-03 (Firefox desktop 140+, Android 142+).
- **A8 keeps its 2026-11-16 date.** The AMO submitting page does not say that the add-on ID is permanent; the
  claim rests on `brand/README.md` and has not been confirmed against an AMO page.
- **Mozilla updates the Add-on Policies on 2026-12-01** (stated on the policies page, with preview versions
  published). Not read here and not adopted; re-read A7 after that date if a submission is still pending.
- **AMO's default reviewer build environment** is now stated on the source-code page: Ubuntu 24.04, Node 24.14.0
  and npm 11.9.0. This project pins Node 24.22.1 in `.nvmrc`, so the reviewer notes must name that version
  (`docs/release.md`, "AMO reviewer notes").
